Official APK decompilation and model asset analysis (Model ID `051412` for RMA2412 / `realme Buds Wireless 5 ANC`) resolved all unresolved vendor features:
1. Volume Enhancer (`ITEM_SOUND_ENHANCE`): GET `0x0110` (response `0x8110`), SET `0x0407` (`[0x01]` enable, `[0x00]` disable). (Note: `0x0107` is Upgrade Capability).
2. ANC Button Mode-List Cycling: Configured via action `2` of `NOISE_LEVEL_COMMAND` (`0x010C` GET with `[0x02, 0x01]`, `0x0404` SET with `[0x02, 0x01, cycleValue]`). Valid wire modes: ANC and Off (`3`), ANC and Transparency (`9`), Transparency and Off (`10`), All modes (`11`).
3. Preset EQ IDs: Confirmed Nature Balance (`0`), Bass Boost (`1`), Clear Vocals (`2`), Clear Bass (`3`), and Custom (`4`). `selectEq` supports IDs `0..3` directly.
4. Spatial Audio: Validated as standard switch feature ID `27` (`0x1B`) via `0x010D`/`0x0403`. Speculative proprietary opcode `0x041E` was disproved and rejected.

All resolved features are integrated into `HeadsetProtocol`, `HeadsetCapabilities`, `HeadsetSession`, `HeadsetController`, `HeadsetSnapshot`, `SwitchCatalog`, and Compose UI (`UnlinkApp`).
Unit tests added and verified in `HeadsetProtocolTest`, `HeadsetSnapshotTest`, `HeadsetSemanticsTest`, and `SwitchCatalogTest`.
Durable docs updated in `context/MAP.md`, `context/CONVENTIONS.md`, `context/DECISIONS.md`, and `README.md`.
